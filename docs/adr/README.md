# Architecture Decision Records

ASCに関する重要な設計判断を記録する。

## 状態

- Proposed: 提案中
- Accepted: 採用
- Superseded: 後続ADRによって置き換え
- Rejected: 不採用
- Deprecated: 現在は推奨しない

## 命名

```text
ADR-0001-project-scope.md
ADR-0002-gitops-first.md
```

番号は連番とし、既存番号を再利用しない。

## 構成

各ADRは原則として次の構成を持つ。

- 状態
- 背景
- 決定
- 理由
- 影響
- 代替案
